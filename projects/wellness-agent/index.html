AI AGENT · APPLICATION PROTOTYPE

康养智能助手Wellness AI Assistant

面向移动端康养场景，探索如何把知识检索、任务路由、工具调用和多轮对话组织成可测试的智能助手工作流。

A mobile wellness assistant prototype exploring how retrieval, task routing, tool use, and multi-turn dialogue can be organized into a testable agent workflow.

RAGTask RoutingWorkflow OrchestrationStructured OutputDevice Testing
01

知识与检索Knowledge and Retrieval

通过检索增强生成连接结构化知识与用户问题，并关注召回内容的相关性、来源边界和回答可追溯性。

Retrieval-augmented generation connects structured knowledge with user questions, with attention to relevance, source boundaries, and traceability.

02

智能体编排Agent Orchestration

使用任务路由、工具调用、对话记忆与结构化输出组织多步骤流程，使不同能力可以按场景组合。

Task routing, tool calls, dialogue memory, and structured outputs organize multi-step workflows and compose capabilities by scenario.

03

产品验证Product Validation

围绕应用端与小程序原型开展交互流程、用户画像和终端测试，验证智能助手的使用路径与产品假设。

Application and mini-program prototypes support interaction-flow, user-profile, and device testing to examine usage paths and product assumptions.
