NUS VISITING PROGRAM · AI

Road to ChatGPT：自然语言处理与情感分析Road to ChatGPT: NLP and Sentiment Analysis

在新加坡国立大学“人工智能与 ChatGPT”访问项目中，围绕文本预处理、词嵌入、情感分类与 Transformer 语言模型完成课程实验和英文汇报。

A visiting-program project at the National University of Singapore covering text preprocessing, word embeddings, sentiment classification, Transformer language models, and an English technical presentation.

NUS2025.07–2025.09TensorFlow 2NLPTransformer
01

情感分析Sentiment Analysis

基于 IMDB 电影评论数据构建英文文本分类流程，完成清洗、分词、向量化、词嵌入与神经网络训练。

An English text-classification pipeline was built on IMDB movie reviews, covering cleaning, tokenization, vectorization, embeddings, and neural-network training.

02

模型比较Model Comparison

比较学习率、优化器、Embedding 维度、网络深度、Dropout 与 L2 正则化对训练和泛化的影响。

Experiments compared learning rates, optimizers, embedding dimensions, network depth, dropout, and L2 regularization.

03

语言模型Language Modeling

学习 Transformer 编码器、自回归文本生成与温度采样，并梳理从词表示到生成模型的核心路径。

The project covered Transformer encoders, autoregressive text generation, temperature sampling, and the path from word representations to generative models.
